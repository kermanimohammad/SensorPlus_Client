# DigitalTwin Project Setup and Usage

## Quick Start
1. Install dependencies:
   npm install

2. Start the database server (REQUIRED for sensor history):
   node server.js
   # OR use the batch file: start-server.bat (Windows) or start-server.sh (Linux/Mac)

3. Start the development server:
   npm run dev

4. Build for production:
   npm run build

## Deployment Options
- Local development: npm run dev:full
- Online deployment: npm run start:online
- See DEPLOYMENT_GUIDE.md for detailed instructions

## Sensor History Feature
- The "Show History" button in the Properties panel requires the database server to be running
- If you get "Failed to fetch" errors, make sure the server is running on port 3001
- The server connects to a MySQL database for historical sensor data

## Troubleshooting
- Database connection errors: Check if server.js is running
- "Failed to fetch" errors: Server not running, start with `node server.js`
- Network errors: Check firewall settings and port 3001 availability
